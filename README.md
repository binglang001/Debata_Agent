# Diana QQ 机器人

Diana 是一个基于 NoneBot2 和 DeepSeek API 开发的 QQ 机器人。她具有独特的“定时主动发言”机制，像一个有独立节奏的小 AI，会定期根据对话历史生成问候或思考，而不是被动回复每一条消息。同时，她能够记住对话历史（持久化存储）并区分不同的用户。

## ✨ 功能特性

- **定时主动发言**：每 30 秒自动调用 AI 判断是否说话，若决定发言则通过私聊发送给你。
- **对话历史持久化**：所有聊天记录自动保存到 `memory.json`，机器人重启后仍能记住之前的对话。
- **用户识别**：自动提取发送者的 QQ 昵称（群聊中优先使用群名片），并在历史中记录用户身份。
- **私聊支持**：目前版本仅响应私聊消息并主动发送给指定 QQ 号。
- **高度可配置**：可轻松修改主动问候间隔、发送目标（私聊/群聊）及 AI 参数。

## 🛠️ 技术栈

- Python 3.10+
- NoneBot2
- OneBot V11 适配器
- NapCatQQ（协议端）
- DeepSeek API（AI 模型）
- asyncio
