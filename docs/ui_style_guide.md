# Diana_Agent UI 风格指南

> 「砚台旁有墨，纸上有空」

本文档定义 Diana_Agent 全部图形界面的视觉语言、文案口吻、交互节奏。
所有 PySide6 组件都应遵循本指南。**新增界面前必读。**

---

## 一、设计哲学

### 三个一句话

1. **现代极简为骨，中国古典为饰**。先是个清爽的现代软件，然后才是有诗意的东方软件。绝不本末倒置。
2. **留白即设计**。中国画讲究"计白当黑"，UI 也是。宁可少放一个元素，不要把空间塞满。
3. **文案有温度，但不撒娇**。说话像有学识的朋友，不像客服机器人，更不像贴吧网友。

### 严格禁止的"中国风俗套"

下列元素**绝对不允许**出现在任何界面中：

- ❌ 红灯笼、福字、剪纸、对联
- ❌ 水墨晕染背景、毛笔笔触纹理
- ❌ 大红 (#FF0000) + 金黄 (#FFD700) 的春晚配色
- ❌ 龙凤纹样、祥云、回字纹边框
- ❌ "古风字体"如汉仪柳体、华文行楷
- ❌ 卷轴形 UI、镂空木窗形按钮
- ❌ 任何 "中国风 + 二次元" 的拼贴感

我们要的是 **2026 年的现代东方软件**，不是 2008 年的"中国风网站"。

## 二、配色系统

### 主色板：宣纸与墨

```
─── 纸色（浅色主题）────────────────────────
宣纸白  #F8F5EE   背景主色
素纸白  #FCFAF4   卡片/面板
落霞黄  #F0E8D6   悬停态浅色填充
温骨色  #E8E1CE   分隔线 / 极轻边框

─── 墨色（深色主题）────────────────────────
夜墨黑  #1A1817   背景主色
浓墨灰  #232120   卡片/面板
淡墨灰  #2E2B28   悬停态深色填充
枯笔灰  #3A3633   分隔线 / 极轻边框

─── 字色 ─────────────────────────────────
浅色主题文字  #2B2622   主要文字（接近黑但有暖度）
浅色次要文字  #6B635A   次要文字 / 说明
浅色禁用文字  #B5AC9F   占位符 / 禁用态

深色主题文字  #E8E2D4   主要文字（接近白但有暖度）
深色次要文字  #9B9286   次要文字 / 说明
深色禁用文字  #5C544A   占位符 / 禁用态
```

### 点缀色：克制使用，单界面≤2 种

```
青瓷青   #6FA39A    主操作按钮 / 链接 / 激活态
汝窑蓝   #5A7A99    辅助强调 / 状态徽章
朱砂红   #C0584F    错误 / 危险操作（饱和度刻意压低）
栀子黄   #D9A85F    警告 / 待办标记
苔色绿   #7A9B6E    成功 / 已连接
```

**使用规则**：
- 同一屏不超过 2 种点缀色（青瓷青 + 一种状态色）
- 点缀色用于"需要被看到的小元素"，不做大面积填充
- 大面积色块永远用纸色/墨色

### 透明度梯度（用于叠加层）

```
8%     轻轻悬停
12%    选中态
20%    弹窗遮罩
40%    禁用态遮罩
```

## 三、字体系统

### 中文字体（按优先级降序回退）

```
标题 / 装饰：
  思源宋体 CN > Source Han Serif CN > Noto Serif CJK SC > 宋体

正文 / UI：
  思源黑体 CN > Source Han Sans CN > Noto Sans CJK SC > PingFang SC > Microsoft YaHei UI > 微软雅黑

等宽 / 代码：
  Sarasa Mono SC > JetBrains Mono > Consolas > Courier New
```

### 英文/数字字体

```
正文：Inter > -apple-system > Segoe UI
等宽：JetBrains Mono > Consolas
```

### 字号阶梯（PySide6 用 px，1pt ≈ 1.33px）

```
T1  装饰大标题       28px / 思源宋体 / weight 500 / line 1.4
T2  小节标题         20px / 思源宋体 / weight 500 / line 1.4
T3  卡片标题         16px / 思源黑体 / weight 600 / line 1.4
正文 默认            14px / 思源黑体 / weight 400 / line 1.6
次要 说明文字        13px / 思源黑体 / weight 400 / line 1.6
微小 元数据/时间戳   12px / 思源黑体 / weight 400 / line 1.5
代码 monospace       13px / 等宽 / line 1.5
```

**字间距**：所有中文字体设置 `letter-spacing: 0.02em`。中文字体没有字间距时显得"挤"。

## 四、间距与栅格

### 间距阶梯（8 倍数）

```
xs   4px    极紧凑（图标内边距）
sm   8px    紧凑（行内元素间距）
md   16px   默认（卡片内边距、组件间距）
lg   24px   宽松（区块间距）
xl   40px   大留白（页面分块）
xxl  64px   超大留白（首屏标题与下方内容）
```

### 卡片内边距

```
小卡片   16px
中卡片   24px
大卡片   32px
```

### 圆角

```
微圆角   4px    输入框 / 小按钮 / 标签
默认     8px    卡片 / 大按钮
大圆角   12px   弹窗 / 模态层
特殊     999px  徽章 / 头像
```

## 五、组件规范

### 按钮

**主按钮（青瓷青填充）**
- 用于一屏内最重要的一个动作（"开始配置"、"保存并继续"）
- 一屏只能有一个主按钮
- 高度 36px，圆角 8px，padding 8px 20px
- 悬停态：背景变深 8%
- 按下态：背景变深 12%
- 字体：14px / 思源黑体 / weight 500

**次按钮（透明 + 边框）**
- 用于辅助操作（"上一步"、"取消"）
- 边框颜色：温骨色 / 枯笔灰
- 悬停态：背景填充落霞黄 / 淡墨灰

**文字按钮（无边框）**
- 用于轻量级跳转（"了解更多"、"查看文档"）
- 字色用青瓷青
- 悬停态：加下划线

**危险按钮（朱砂红填充）**
- 仅用于不可逆操作（"删除人格"、"清空记忆"）
- 必须配合二次确认弹窗

### 输入框

- 高度 36px，圆角 4px，padding 0 12px
- 边框：温骨色 / 枯笔灰，1px
- 焦点态：边框变青瓷青，添加 2px 外发光（rgba(111, 163, 154, 0.15)）
- 错误态：边框朱砂红
- 占位符颜色：浅色禁用文字 / 深色禁用文字

**API 密钥输入框特殊处理**：
- 默认遮蔽显示（圆点）
- 右侧带"显示/隐藏"小图标
- 配套"测试连接"按钮（成功时图标变苔色绿对勾，失败时朱砂红叉）

### 卡片

- 背景：素纸白 / 浓墨灰
- 圆角 8px
- 默认无边框，浮起感来自微弱阴影：`0 1px 3px rgba(0, 0, 0, 0.04)`
- 浅色主题下若需边框：1px 温骨色

### 列表项（聊天可视化用）

- 高度 64px（头像 40px + 上下 12px）
- 悬停态：背景落霞黄 / 淡墨灰
- 选中态：左侧 3px 青瓷青竖条 + 浅填充

### 徽章（状态指示）

```
[ 已连接 ]      苔色绿背景 + 白字 / 圆角 4px / padding 2px 8px / 12px 字号
[ 连接中 ]      栀子黄背景 + 白字
[ 未连接 ]      浅色次要文字色边框 + 同色字
[ 出错 ]        朱砂红背景 + 白字
```

### 弹窗

- 圆角 12px
- 遮罩：rgba(0, 0, 0, 0.2)（浅色）/ rgba(0, 0, 0, 0.6)（深色）
- 标题：T2 思源宋体
- 间距：标题与正文间 24px，正文与按钮区 32px
- 按钮区右对齐，次按钮在左，主按钮在右

## 六、图标语言

### 风格

- **线性图标**为主，1.5px 描边，圆角端点
- **不使用面性图标**（实心图标）
- 24x24 为基准尺寸，可缩放到 16x16 / 20x20 / 32x32

### 推荐图标库

- **Phosphor Icons**（线性风格，描边均匀，与本风格高度匹配）
- **Lucide**（备选）
- 不用 Material Icons（面性图标多，与本风格冲突）

### 自定义图标（少量必要时）

如需自制几枚装饰图标（比如启动 Logo、空状态插画），可用以下东方元素**节制使用**：

- 简化的"砚"形（菱形带凹陷）
- 简化的"卷"形（细长矩形）
- 单笔的"墨点"（小圆点带轻晕染）

绝不使用复杂的传统纹样。

### Logo

主 Logo 设计原则（**待 P2 时由 Claude 给出最终方案**）：
- 主体是一枚极简的"印章感"图形（不是真的印章纹理，是抽象化）
- 配字 "Diana_Agent" 用思源宋体
- 单色，能在浅 / 深主题下都不丢失辨识度

## 七、动效

### 基本原则

- **快、轻、不打扰**。任何动画 ≤ 200ms。
- **缓动函数**：默认用 `cubic-bezier(0.4, 0, 0.2, 1)`（Material 标准 ease）。
- **滥用动画的减分项**：超过 300ms 的过渡、bounce 弹动、淡入旋转。

### 具体场景

```
按钮悬停态变色          120ms ease-out
弹窗打开/关闭           200ms ease-out
列表项选中              150ms ease-out
内容切换淡入            180ms ease-out（仅 opacity，不要 transform）
状态徽章变化            200ms ease-out
打字光标                500ms 周期闪烁
```

### 不要做的

- ❌ 内容大幅位移（slide-in 距离 > 16px）
- ❌ 旋转动画作为主要过渡
- ❌ 翻转、3D 效果

## 八、文案口吻

### 总原则

- **不机械**：避免"错误代码 -1"、"操作成功"、"请稍候"
- **不撒娇**：避免"哎呀！出错啦~"、"小助手正在为您服务呢"
- **像有学识的朋友**：克制、准确、偶尔有点墨水

### 通用表达对照

| 不要写 | 改写为 |
|--------|--------|
| 操作成功 | 已完成 / 已就位 / 已记住 |
| 操作失败 | 未能完成（附原因）/ 此处暂行不通 |
| 加载中 | 正在准备 / 稍等片刻 |
| 错误 | 出了点状况 / 此处不太对 |
| 警告 | 留意 / 此处需要确认 |
| 确认 | 是的 / 就这样 |
| 取消 | 算了 / 再想想 |
| 删除 | 移除 / 抹去 |
| 重试 | 再试一次 / 再来 |

### 空状态文案

空状态是最能体现品味的地方。**给一句静的话，不要喋喋不休。**

```
聊天列表空：
  暂无对话
  ——————
  机器人就位后，往来的消息会显示在这里

历史记忆空：
  尚未记下什么
  ——————
  对话中若有值得记住的事，会自动记录在此

日志空：
  日志为空
```

**避免**：

- ❌ "快来添加好友开启对话吧！"
- ❌ "您还没有任何聊天记录哦~"
- ❌ "Add your first contact"

### 错误消息文案模板

```
[简短一句说出问题] + [一个补充信息] + [可选的下一步建议]

例：
  连接 NapCat 未能建立
  网络可能不通，或 NapCat 未启动
  → [重新尝试] [查看排查指南]

  此 API 密钥不被接受
  服务端返回 401，请确认密钥是否正确
  → [重新填写]
```

### 标题文案

向导步骤标题用**短句**，不用"第 X 步：XXX"这种机械结构：

```
✅ "选个主模型"
✅ "告诉我你的角色"
✅ "把 NapCat 接上"

❌ "第 1 步：API 配置"
❌ "Step 2: Persona Setup"
```

## 九、深浅主题切换

### 默认行为

- 首次启动：跟随系统主题
- 用户手动切换后：记住选择，不再跟随系统
- 切换瞬间：颜色用 200ms 过渡（避免硬切感）

### 切换入口

仪表盘右上角一个小图标按钮（月亮/太阳切换）。**不放在向导里**——首次配置时不让用户在主题上分心。

## 十、可访问性

- **对比度**：所有文字与背景对比度 ≥ 4.5:1（WCAG AA）
- **键盘导航**：所有按钮 / 输入框 / 列表项可 Tab 聚焦，焦点态用青瓷青 2px 外环
- **错误提示**：不只用颜色表达。错误态除了边框变红，还要有图标 + 文字说明
- **字号缩放**：所有 UI 在系统字号 125% / 150% 下不破版

---

## 十一、引用与灵感

本风格的灵感来源（这些是我们想接近的品味，**不是要抄袭**）：

- **Linear**（dark theme 的克制感）
- **Notion**（信息层级的清晰）
- **Anthropic Console**（极简但有温度）
- **Kindle 阅读器**（纸质感的处理）
- **得到 App 早期版本**（中文版式的呼吸感）

不参考的（与本风格冲突）：
- Discord、Slack（太过年轻态）
- 微信桌面版（系统感重，不像独立软件）
- 任何"国风"游戏 UI（装饰过度）

---

## 十二、给开发者的最后提醒

> 写 UI 时如果发现自己在想"再加点装饰会不会更好"，**停下，撤销**。
> 本风格的核心是减法，不是加法。
> 一份留白胜过十处装饰。
