# 获取 OpenRouter API Key

OpenRouter 聚合了几乎所有主流模型，一个 Key 通吃。适合想同时用多家模型的场景。

## 1. 注册

打开 [OpenRouter](https://openrouter.ai)，用 GitHub 或 Google 账号登录。


## 2. 创建 API Key

右上角头像 → Keys → **Create Key**。复制保存。


## 3. 计费

按 token 计费，不同模型价格不同。需要先充值才能用。详见 [OpenRouter 定价](https://openrouter.ai/models)。

## 4. 填入 Debata

向导自定义路径 → 选 **OpenRouter** → 粘贴 API Key → 选模型 → 保存。
