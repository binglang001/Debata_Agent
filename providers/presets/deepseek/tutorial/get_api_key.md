# 获取 DeepSeek API Key

DeepSeek 是目前中文对话性价比最高的选择，KV 缓存命中率高，推荐作为主模型。

## 1. 注册

打开 [DeepSeek 开放平台](https://platform.deepseek.com/sign_in)，用手机号或邮箱注册。

![DeepSeek 首页](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_deepseek_home.png)

## 2. 实名认证

左边菜单 → 充值 → **上方“去认证”**。完成实名认证，点击“提交认证”

![创建 Key](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_deepseek_real_name_authentication.png)

## 3. 创建 API Key

左边菜单 → API Keys → **创建 API Key**。取个名字（比如 "Debata"），复制生成的 key。

![创建 Key](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_deepseek_create_key.png)

Key 只显示一次，立刻复制保存。

![复制 Key](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_deepseek_copy_key.png)

## 4. 充值

DeepSeek 是预付费制。左边菜单 → 充值，建议先充 5 块钱，够个人用很久。

## 5. 填入 Debata

向导推荐路径第一步就是 DeepSeek。粘贴 API Key，点「测试连接」，通过后继续。
