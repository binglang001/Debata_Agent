# 获取 OpenAI API Key

## 1. 注册

打开 [OpenAI Platform](https://platform.openai.com)，用邮箱注册。


## 2. 创建 API Key

右上角头像 → API Keys → **Create new secret key**。取个名字，复制 key。


Key 只显示一次。


## 3. 充值

OpenAI 是预付费制。进 [Billing](https://platform.openai.com/settings/organization/billing/overview) 绑定信用卡并充值。

## 4. 填入 Debata

向导自定义路径 → 选 **OpenAI** → 粘贴 API Key → 选模型（如 gpt-4o）→ 保存。
