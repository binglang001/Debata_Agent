# 获取通义千问 API Key

阿里云通义千问系列，中文强，多模态模型选择多。

## 1. 注册

打开 [阿里云百炼](https://bailian.console.aliyun.com)，用阿里云账号登录。


## 2. 创建 API Key

控制台 → API-KEY → **创建 API-KEY**。复制保存。


## 3. 计费

按 token 计费，部分模型有免费额度。详见 [百炼定价](https://help.aliyun.com/zh/model-studio/getting-started/models)。

## 4. 填入 Debata

向导自定义路径 → 选 **通义千问** → 粘贴 API Key → 选模型（如 qwen3-flash）→ 保存。
