# 获取 Together AI API Key

Together AI 托管了大量开源模型（Llama、Qwen、DeepSeek 等），全部走 OpenAI 兼容 API。

## 1. 注册

打开 [Together AI](https://api.together.xyz)，用 GitHub 或 Google 账号登录。


## 2. 创建 API Key

进 [API Keys 页面](https://api.together.xyz/settings/api-keys)，点 **Create API Key**。


复制生成的 key，这之后不会再显示。


## 3. 计费

[按 token 计费](https://www.together.ai/pricing)，不同模型价格不同。新用户通常有 $1 免费额度。注意大模型（Llama 70B 等）单价较高。

## 4. 填入 Debata

启动向导 → 选 **Together AI** → 粘贴 API Key → 选模型 → 保存。
