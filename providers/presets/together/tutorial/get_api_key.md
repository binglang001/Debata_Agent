# 获取 Together AI API Key

Together AI 是一个开放模型平台，托管了大量主流开源模型（Llama、Qwen、DeepSeek 等），全部走 OpenAI 兼容 API。

## 1. 注册

前往 [Together AI](https://api.together.xyz) 注册账号。支持 GitHub / Google 快捷登录。

## 2. 获取 API Key

登录后进 [API Keys 页面](https://api.together.xyz/settings/api-keys)，点「Create API Key」生成。新用户通常有 $1 免费额度。

## 3. 计费

按 token 计费，不同模型价格不同。详见 [Together 定价](https://www.together.ai/pricing)。注意部分大型模型（如 Llama 70B）单价较高。

## 4. 填入 Debata

启动向导 → 选「Together AI」→ 粘贴 API Key → 选模型 → 保存。
