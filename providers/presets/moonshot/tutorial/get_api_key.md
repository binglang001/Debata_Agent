# 获取 Moonshot API Key

Moonshot（月之暗面）的 Kimi 系列模型，长上下文处理见长。

## 1. 注册

打开 [Moonshot 开放平台](https://platform.moonshot.cn)，用手机号注册。


## 2. 创建 API Key

控制台 → API Keys → **创建 API Key**。复制保存。


## 3. 计费

按 token 计费。详见 [Moonshot 定价](https://platform.moonshot.cn/pricing)。

## 4. 填入 Debata

向导自定义路径 → 选 **Moonshot** → 粘贴 API Key → 选模型（如 moonshot-v1-8k）→ 保存。
