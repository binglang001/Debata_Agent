# 获取火山方舟 API Key

字节跳动旗下，豆包系列模型，视觉和 Embedding 都有不错表现。

## 1. 注册

打开 [火山方舟控制台](https://console.volcengine.com/ark)，用手机号注册。

![火山首页](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_volcengine_home.png)

## 2. 创建 API Key

登录后的页面中，点击左侧“API Key管理” → **创建 API Key**。填入名称“Debata”，点击确认后，点击刚刚创建的密钥的API Key一栏右侧的显示图标，随后复制保存。

![创建 Key](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_volcengine_create_key.png)

## 3. 开通模型

点击左侧“开通管理” → 向下滑找到“Doubao-Seed-2.0-lite”和上方“向量模型”标签中的“Doubao-embedding-vision” → 点击右侧“开通服务”。在弹窗中点击“确定开通与授权”。

![创建 Key](https://raw.githubusercontent.com/binglang001/Debata_Agent/main/docs/images/tutorial_volcengine_open_model.png)

## 4. 填入 Debata

向导自定义路径 → 选 **火山方舟** → 粘贴 API Key → 选模型 → 保存。
