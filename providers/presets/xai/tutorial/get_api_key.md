# 获取 xAI API Key

xAI 提供 Grok 系列模型，API 走 OpenAI 兼容协议。

## 1. 注册

打开 [xAI API 控制台](https://console.x.ai)，注册账号。需要绑信用卡。


## 2. 创建 API Key

登录后在 Dashboard 或 API Keys 页面点 **Create API Key**。Key 只显示一次，立刻复制保存。



## 3. 计费

[按 token 计费](https://x.ai/api-pricing)，每月有免费额度（额度可能变动，以官网为准）。

## 4. 填入 Debata

启动向导 → 选 **xAI Grok** → 粘贴 API Key → 选模型 → 保存。或设置页 Models 节手动加。
