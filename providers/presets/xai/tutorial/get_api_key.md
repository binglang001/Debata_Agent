# 获取 xAI API Key

xAI 是 Elon Musk 创立的 AI 公司，提供 Grok 系列模型。API 走 OpenAI 兼容协议，Debata 可直接对接。

## 1. 注册

前往 [xAI API 控制台](https://console.x.ai) 注册账号。需要绑定信用卡或借记卡。

## 2. 获取 API Key

登录后在 Dashboard 或 API Keys 页面点击「Create API Key」，复制保存。Key 只会显示一次。

## 3. 计费

按 token 计费，价格见 [xAI 定价页](https://x.ai/api-pricing)。每月有免费额度（额度可能变动，以官网为准）。

## 4. 填入 Debata

启动向导 → 选「xAI Grok」→ 粘贴 API Key → 选模型 → 保存。或手动在设置页 Model 节添加。
