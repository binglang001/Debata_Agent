# 获取硅基流动 API Key

硅基流动（SiliconFlow）提供开源模型托管，DeepSeek、Qwen 等模型都有。

## 1. 注册

打开 [硅基流动](https://siliconflow.cn)，用手机号注册。


## 2. 创建 API Key

控制台 → API Keys → **创建 API Key**。复制保存。


## 3. 计费

按 token 计费，新用户有免费额度。详见 [硅基流动定价](https://siliconflow.cn/pricing)。

## 4. 填入 Debata

向导自定义路径 → 选 **硅基流动** → 粘贴 API Key → 选模型 → 保存。
