# 获取 Anthropic API Key

Claude 系列模型，深度思考和长上下文能力突出。

## 1. 注册

打开 [Anthropic Console](https://console.anthropic.com)，用邮箱或 Google 账号注册。


## 2. 创建 API Key

左边菜单 → API Keys → **Create Key**。取个名字，复制 key。


## 3. 充值

进 [Billing](https://console.anthropic.com/settings/billing) 绑定信用卡，按用量扣费。

## 4. 填入 Debata

向导自定义路径 → 选 **Anthropic Claude** → 粘贴 API Key → 选模型（如 claude-sonnet-4-6）→ 保存。
