# 获取 Google Gemini API Key

Gemini 系列模型，原生多模态支持，免费额度大方。

## 1. 获取 Key

打开 [Google AI Studio](https://aistudio.google.com/apikey)，用 Google 账号登录，点 **Create API Key**。


## 2. 计费

免费额度足够个人日常使用。超量后按 token 计费。详见 [Gemini 定价](https://ai.google.dev/pricing)。

## 3. 填入 Debata

向导自定义路径 → 选 **Gemini** → 粘贴 API Key → 选模型（如 gemini-2.5-flash）→ 保存。
